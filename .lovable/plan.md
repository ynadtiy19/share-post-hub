# 文章分享页：主域名/文章id

## 目标

1. 先把你仓库（上传的压缩包内容）里的完整站点还原到这个项目里，恢复现有落地页。
2. 新增文章详情页，地址形如 `主域名/6aaf3ff93e470748cd34746f`。
3. 页面能自动识别三种帖子类型（长文、图文说说、投票），并把长文里的各种排版（标题、加粗、引用、列表、链接、图片标注等）正确渲染出来。
4. 风格延续现有主页的温和米色/鼠尾草绿基调。

## 第一步：还原现有站点

把压缩包里的源码（页面、组件、图片、文案、样式）复制进项目，不带任何 Git 相关文件，并补齐所需依赖。完成后主页恢复成你仓库里的样子。

## 第二步：文章数据获取

- 使用 `https://googlechat.zeabur.app/api-posts/{id}`（实测可正常返回数据）。
  文档里的 `/admin/posts/{id}/share` 目前会返回“管理员凭证缺失”，所以先不接；等它上线后只需换一个地址即可。
- 请求由服务端发起（页面打开时在服务器侧取数据），这样不受浏览器跨域和来源域名白名单影响，预览环境也能正常显示；同时首屏直接带内容，利于分享时抓取标题、摘要和封面图。
- 取不到或 ID 不存在时，显示一个同风格的“文章不存在”页面，而不是报错白屏。

## 第三步：三种帖子类型的展示

- **长文（quill）**：标题 + 作者 + 时间 + 正文。
- **图文说说（short_post）**：文字 + 图片画廊（单图大图、多图网格，可点击放大）。
- **投票（poll）**：问题 + 选项列表，每个选项显示票数和占比条（只读展示，不提供投票）。
- 三种都带底部的浏览/点赞/收藏/评论数一栏，和作者头像、昵称、简介。

## 第四步：长文排版渲染

自己实现一个 Delta 渲染器，把接口返回的内容逐段转换成网页元素，支持：

- 段落与换行、一级/二级/三级标题
- 加粗、斜体、下划线、删除线、行内代码、文字颜色/背景色
- 引用块（含开头 `❝` 这类引用文字）、代码块、有序/无序列表、缩进、对齐
- 超链接（新窗口打开）
- 图片：支持 `custom_image` 这种内嵌格式，读取图片地址、说明文字和宽度比例，图片下方显示灰色小字标注
- 视频：支持后续加入的视频链接与视频标注，直接内嵌播放器并在下方显示标注；无法识别的嵌入类型退化为一个可点击的链接，不会让页面崩掉

排版风格与主页一致：衬线标题、舒适行高、克制的留白。

## 第五步：分享与收尾

- 页面标题、描述、封面图按文章内容动态生成，分享到聊天工具时有预览卡片。
- 顶部保留返回主页入口，移动端优先排版。
- 完成后代码会随项目同步推送到你的 GitHub 仓库分支。

## 技术细节

- 新增 `src/routes/$postId.tsx`，用 loader（服务端）调用 `/api-posts/{id}`，`head()` 输出动态 og 标签。
- 新增 `src/lib/post-api.ts`（请求 + 类型 + 响应归一化，兼容 `likes`/`likes_count` 两种字段）。
- 新增 `src/components/post/` 下的 `QuillDeltaRenderer.tsx`、`PostGallery.tsx`、`PollCard.tsx`、`PostHeader.tsx`。
- 根级动态路由只匹配 24 位十六进制 ID，其余路径照常走 404，不影响以后新增的普通页面。
